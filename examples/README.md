# Examples

## Start with these three

Each example includes English narration, captions, portrait and landscape videos, an interactive player and editable scene files. Open the HTML players from your downloaded checkout. The root [gallery](../samples.html) includes all three.

| Example | Topic |
| --- | --- |
| [What happens between your prompt and the next token?](llm/demo.html) | Tokens, context, probabilities and the generation loop. Start here. |
| [What is Erdős problem 643?](erdos-643/demo.html) | How the same six dots split into triples in two different ways. |
| [Why does “you” change in Vietnamese?](vietnamese-address/demo.html) | How terms of address express relationships between speakers. |

## Templates and verification examples

These smaller examples support new projects and automated checks. They are separate from the three finished videos above.

- [Attention dataflow](attention-dataflow/): a worked attention calculation.
- [KV cache](kv-cache/): reuse during token generation.
- [Linear transformation](linear-transformation/): a geometric transformation.
- [Revenue and contribution](revenue-and-contribution/): a business calculation.
- [Six dots](six-dots/): a counting example.

Keep these folders in place because CLI templates and tests use them. Save your own projects under the ignored `projects/` folder or another workspace.
